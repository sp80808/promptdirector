# Cinematic.AI Studio v5.0 | Documentation

## 🎬 Project Overview
Cinematic.AI is a professional NLE-style (Non-Linear Editor) web application for AI filmmaking. It bridges the gap between traditional cinematic intuition and AI generation mechanics, focusing on **Character Consistency**, **Scene Continuity**, and **Directorial Control**.

## 🧬 Core Features

### 1. The "Character Bible" & Modular Outfits
- **Master Identity**: Lock the face seed and core physical traits.
- **Outfit Variants**: Create "Civilian", "Space Suit", or "Battle Damaged" variants that preserve the Master's facial identity while changing wardrobe.
- **Consistency Locking**: Uses a combination of Seed-locking and LoRA referencing to ensure characters don't "morph" between shots.

### 2. Smart "@" Tagging & Prompt Orchestration
- **Mention System**: Type `@Sarah` or `@Sarah_SpaceSuit` in any prompt field to automatically inject the full character sheet (seed, traits, clothing) into the generation payload.
- **Directorial Translation**: The Orchestrator converts high-level terms (e.g., "35mm anamorphic", "Dolly Zoom") into precise technical tokens for the target model.

### 3. NLE-Style Timeline
- **Non-Linear Editing**: Drag and drop shots between scenes.
- **Multi-Take Workflow**: Render multiple versions of a shot, rate them, and "Approve" the master version.
- **Frame Chaining**: Automatically use the last frame of an approved take as the starting frame (`init_image`) for the subsequent shot.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- API Keys for: Google AI Studio (Gemini), SiliconFlow, or Runway.

### Installation
1.  Navigate to the project directory:
    ```bash
    cd "02_Current_Build/cinematic-ai-studio"
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
