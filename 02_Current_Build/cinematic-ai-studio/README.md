# Cinematic.AI Studio v5.0 | Professional AI Filmmaking

**The Unified NLE for the Generative Era.** Cinematic.AI v5.0 bridges the gap between traditional cinematic intuition and modern AI generation mechanics. It is designed for directors who demand **Character Consistency**, **Scene Continuity**, and **Directorial Control**.

---

## 🚀 Key Features

### 🧠 The "Director's Brain" (State Engine)
- **Character Bible & Forge**: Maintain master identities (seeds/LoRAs) and modular outfit variants.
- **Smart @ Mentions**: Automatically inject full character sheets and location profiles into prompts by tagging them.
- **Auto-Storyboard**: Paste a screenplay and let the AI break it down into shots, characters, and suggested timings.

### 🎬 Production & Continuity
- **Frame Chaining (Init-Image)**: Automatically lock lighting and geometry between cuts by using the previous approved frame as an anchor.
- **Continuity Scan**: AI-driven heuristics that warn of wardrobe mismatches or illegal location jumps within a scene.
- **Cinema Playback**: A full-screen player that handles mixed media (static images + animated videos) with synchronized AI-generated foley.

### 🧬 Advanced Generative Tools
- **AI Inpaint Studio**: Native masking canvas to swap outfits or props with pinpoint precision.
- **Audio Stage**: Prompt-based Foley and Ambient sound generation for every shot.
- **Cinematic DNA**: Mashup film styles (e.g., "Blade Runner + The Revenant") to generate technical cinematographer prompts.
- **Workflow Inspector**: View and copy the raw **ComfyUI API JSON** for every generated frame.

### 🛠 Technical Architecture
- **Framework**: React 19 + Vite + TypeScript
- **State**: Zustand with Persistence
- **UI**: Tailwind CSS 4 (Dark NLE Theme)
- **AI Backend**: Multi-Provider (Google Gemini, SiliconFlow, Runway, Stable Audio)
- **Export**: OpenTimelineIO (.otio) and Markdown Production Bibles
