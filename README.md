# Cinematic.AI: Professional AI Filmmaking Studio

Cinematic.AI is a high-end, NLE-style web application designed for professional AI filmmaking. It bridges the gap between traditional cinematic intuition and AI generation mechanics, focusing on **Character Consistency**, **Scene Continuity**, and **Directorial Control**.

## 🚀 Quick Start

1.  **Enter the Studio**: The active build is located in `02_Current_Build/cinematic-ai-studio/`.
2.  **Configure AI**: Open **Settings** and add your Google AI Studio key to unlock the Auto-Storyboard and Concept engines.
3.  **Start Directing**: Follow the **[User Guide](./USER_GUIDE.md)** for detailed workflows.

## ✨ Key Features

- **Character Forge**: Lock facial seeds and manage outfit consistency across scenes.
- **Auto-Storyboard**: Paste scripts and auto-generate technical shot sequences.
- **Concept Engine**: Generate visual DNA and moodboards for pre-production.
- **NLE Sequencer**: Professional timeline with drag-and-drop and .OTIO export.
- **Smart Tagging**: Director-centric @mention system for character and optics injection.
